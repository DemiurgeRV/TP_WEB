## Домашнее задание №1
### Первоначальная верстка сайта
В данной работе была выполнена подготовка статической верстки сайта 
с помощью bootstrap. Bootstrap является предустановленным.
Были сделаны соответствующие файлы(страницы):
- base.html - шаблон для каждой страницы сайта;
- index.html - страница вопросов(главная страница сайта);
- ask.html - страница формы создания вопроса;
- question.html - страница вопроса(с ответами):
- login.html - форма входа;
- signup.html - форма регистрации;
- styles.css - файл стилей;
- img - директория изображений-заглушек.

Всё задание было выполнено в соответствии с требованиями.
